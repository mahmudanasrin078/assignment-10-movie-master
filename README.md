# Toys World

**Toys World** is a modern web application designed to showcase, explore, and manage a collection of toys. It provides an engaging and responsive user interface where users can browse toys by categories, view detailed information, and manage their favorites — all powered by React, Firebase, and Tailwind CSS.

🎯 Purpose

The purpose of **Toys World** is to offer a seamless platform for toy enthusiasts and collectors to explore a variety of toys online. It focuses on a clean design, smooth animations, and an intuitive user experience using the latest frontend technologies.

---

✨ Key Features

Dynamic Routing:
Implemented using `react-router` for smooth navigation.

Firebase Integration:
Secure user authentication and data storage.

User Authentication:
Users can register and log in using Firebase Authentication.

Login & Register Pages:

Login:
Existing users can securely log in to their accounts.

Register:
New users can create an account using email and password.

Tailwind CSS:
Fast, responsive, and customizable UI design.

Animations on Scroll:
Enhanced visuals using `AOS` library.

Notifications:
Toast messages using `react-toastify`.

Loading Indicators:
Beautiful loaders via `react-spinners`.

Reusable Icons:
Implemented with `react-icons`.

Responsive Design:
Works perfectly on all devices.
